Bu portfolio saytida quyidagilarni topishingiz mumkin:

- Men haqimda qisqacha ma'lumot
- Ko'nikmalarim va texnologiyalar
- Bajargan loyihalarim
- Men bilan bog'lanish usullari

## 📁 Loyiha tuzilishi

```
portfolio/
├── index.html      # Asosiy sahifa
├── style.css       # Stillar
├── script.js       # JavaScript
├── assets/         # Rasmlar, ikonkalar
└── README.md       # Hujjat
```

## 🚀 O'rnatish va ishga tushirish

1. Repozitoriyni klonlang:

   ```bash
   git clone https://github.com/username/portfolio.git
   ```

2. Papkaga kiring:

   ```bash
   cd portfolio
   ```

3. `index.html` faylini brauzerda oching.

   Yoki lokal server bilan ishga tushiring:

   ```bash
   npx serve
   ```

## 🎨 Moslashtirish

- **Shaxsiy ma'lumotlar:** `index.html` ichidagi ism, kasb va tavsifni o'zgartiring.
- **Loyihalar:** "Loyihalar" bo'limiga yangi kartochka qo'shing (nom, tavsif, havola).
- **Ranglar:** `style.css` boshidagi rang o'zgaruvchilarini tahrirlang.
- **Rasm:** `assets/` papkasiga o'z rasmingizni joylang.

## 🌐 Deploy qilish

Sayt statik bo'lgani uchun uni bepul joylashtirish mumkin:

- **GitHub Pages** — Settings → Pages → branch tanlang
- **Netlify** — papkani sudrab tashlang yoki GitHub bilan ulang
- **Vercel** — repozitoriyni import qiling
